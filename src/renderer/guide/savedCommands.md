# Saved commands

A saved command is one you run often, such as a dev server, with a name and the folder it runs in. Saved commands are listed under Saved commands in the sidebar.

- Save one with {new-command}, or the + next to Saved commands. Give it a name and the command, and a folder if it should not start in your home folder.
- Run it with a click. It opens in a tab of its own and types the command into a new shell, which stays open when the command ends.
- Turn on the bolt next to it, and it starts every time Termi opens.
- Edit it with the pencil next to it. The edit dialog also deletes it.
